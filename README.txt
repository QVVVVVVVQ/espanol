Español — локальный HTML-тренажёр

Откройте index.html в браузере. Сервер не нужен.

Темы:
- Цвета
- Дни недели
- Месяцы
- Глагол SER в настоящем времени (местоимения + простые школьные примеры)

Режимы: карточки, тест, аудирование, диктант, 60 секунд, пары.

Особенности v7:
- В SER основная карточка произносит только местоимение + форму глагола; примеры озвучиваются только по кнопке.
- В SER-тесте примеры появляются после правильного ответа и имеют отдельные кнопки прослушивания.
- Во всех тестовых режимах ошибка сопровождается звуковым сигналом, а текущее задание остаётся до правильного ответа.
- После правильного ответа произносится только правильное слово/форма.
- В «Парах» правильные пары остаются с зелёной рамкой, неправильные кратко подсвечиваются красным со звуковым сигналом.
- Для темы «Цвета» в «Парах» используются цветные кнопки вместо русских названий.

Прогресс и настройки хранятся локально в браузере (localStorage).
